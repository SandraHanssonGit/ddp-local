## Architecture approach

Claude Code should help design the first project architecture.

Before creating files, propose a simple architecture for:

- Node.js + Express server
- SQLite database
- Server-rendered HTML pages
- Tailwind CSS via CDN
- Plain JavaScript only when needed

The architecture should be small, local, and easy to understand.

Do not overengineer the solution.

Do not create files before explaining the proposed structure and getting approval.

The proposed structure should include:

1. Where the Express app starts
2. Where database setup lives
3. Where routes live
4. Where HTML views live
5. Where static files live
6. Where the SQLite database file lives
7. How seed/test data is created

After proposing the structure, wait for my approval before building it.
